# חבילת הסריקה של סטאג'ר משפטי

כלי שקורא את הקוד של המערכת שלך במחשב שלך, ומכין רשימה של התהליכים שמעבדים מידע אישי (עוגיות, ספקים חיצוניים, תשלומים, טפסים ועוד), כדי שעורך דין יוכל להכין את המסמכים המשפטיים של האתר.

**הקוד שלך לא נשלח ולא יישלח.** נשלח קובץ מוצפן עם תיאור התהליכים בלבד.

## איך זה עובד

שני שלבים נפרדים. בשלב הראשון אין שום תקשורת רשת.

1. **סריקה מקומית**

   ```bash
   node dist/lawstager-scan.cjs scan <תיקיית הפרויקט>
   ```

   נכתבים קבצים לתיקייה מוסתרת בשם `.lawstager`. אפשר לקרוא אותם לפני שמשהו נשלח.

2. **שליחה**

   ```bash
   node dist/lawstager-scan.cjs send <תיקיית הפרויקט> --lawyer <מזהה עורך הדין>
   ```

   הכלי מציג כל תהליך שנמצא ושואל אם הוא נכון. אפשר לסמן "לא מסכים" ולכתוב הסבר. בסוף מסמנים הסכמה, ורק אז הקובץ מוצפן ונשלח.

## מה נשלח ומה לא

- נשלחים: תיאור התהליכים שנמצאו, שמות ספקים ודומיינים, הפניות לקובץ ולשורה (בלי קטעי קוד), הפרטים שמילאת, והאישורים וההסתייגויות שסימנת.
- מפתחות, סיסמאות וטוקנים שזוהו מוסרים לפני השליחה. ההסרה מצמצמת סיכון ואינה מבטיחה שלא יישלח מידע מזהה.
- הקובץ מוצפן ונפתח רק בשרת. המעטפת קשורה לשליחה אחת ואינה ניתנת לשימוש חוזר.

## מסלול מאומת

אפשר להריץ את שלב השליחה בתוך GitHub Actions, ואז הדוח מסומן "מאומת" (נבדק שהוא הופק מהקוד בריפו שלך). במסלול המקומי הוא מסומן "לא מאומת".

בקובץ ה-workflow שלך:

```yaml
jobs:
  lawstager:
    permissions:
      contents: read
      id-token: write
    uses: triumtech-dev/Tech_Law_stager/.github/workflows/lawstager-scan-reusable.yml@<SHA מלא של commit>
    secrets:
      answers: ${{ secrets.LAWSTAGER_ANSWERS }}
```

חובה לקבע את הגרסה ל-SHA מלא של commit, ולא לענף או לתג. את תוכן `LAWSTAGER_ANSWERS` מקבלים מהשלב המקומי של `send`: הוא נשמר בתיקייה `.lawstager` ואינו נכנס ל-git. הוא מכיל פרטי קשר, ולכן אסור להכניס אותו לריפו.

## הוק אופציונלי

הוק בודק בכל שינוי בקוד אם השתנה משהו שמשפיע על המסמכים, ושולח דוח שינויים רק אם כן. הוא דורש הסכמה חד-פעמית, אינו מעדכן שום מסמך באתר שלך, ואינו כותב לריפו שלך. ראו `.github/workflows/lawstager-hook-reusable.yml`.

## בנייה

```bash
npm install
npm run bundle
```

הקובץ `dist/lawstager-scan.cjs` הוא תוצר הבנייה, והוא מצורף לריפו כדי שה-workflow יוכל להריץ אותו ב-`node` פשוט, בלי `npm install` ובלי תלויות מהריפו שלך.
